Adds your AutomatePal support chat to every public page of your site.

== Description ==

AutomatePal answers your visitors from your own help content, quotes the source it used, and hands the conversation to your team when a person is needed.

This plugin adds one asynchronous script to the footer of public pages. It does not load anything in wp-admin, store visitor data in WordPress, or set cookies. Settings are a single option, removed when you delete the plugin.

== Installation ==

1. Plugins › Add New › Upload Plugin, choose automatepal-wordpress.zip, then Activate.
2. In your AutomatePal dashboard, open Setup › Install on your site and create or copy your install key.
3. In Widget studio, add this site's exact https address to the allowed origins.
4. Settings › AutomatePal: paste the key and save. Open your site; the chat button appears in the corner.
