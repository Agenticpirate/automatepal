# Demo video script (< 3 min) - AutomatePal

Target: 2:30-2:50. Screen recording, voiceover or captions. Show the app working end to end.

## 0:00-0:15 - Hook
Screen: chat home.
"I'm an indie founder. I just built a $12/month SaaS and I want to start charging. Watch this."

## 0:15-0:50 - Setup by conversation
Type: "I sell ShipFast, a SaaS starter, at $12/month. Set up billing."
Agent creates PayPal product + subscription plan, returns the subscribe link.
Cut to: the subscribe link opening a real PayPal sandbox checkout page.

## 0:50-1:20 - One-time sale + invoice
Type: "Someone just bought my $19 template pack - make a checkout link." Agent returns order approval link.
Type: "Invoice sam@acme.com $240 for a consulting call." Agent creates and sends the invoice.

## 1:20-1:50 - Revenue copilot
Type: "Seed 25 demo subscribers at $12/month."
Switch to the AG Grid dashboard: 25 subscribers, months of renewals streaming in. MRR card climbs.
Type: "What's my MRR and how many failed payments?" Agent answers from the live ledger.

## 1:50-2:20 - Dunning
Type: "Draft dunning emails for everyone whose payment failed."
Agent lists the failed customers and writes a personalized recovery email for each.

## 2:20-2:45 - Wrap
Dashboard zoom out. "Billing setup used to be a week of PayPal integration. AutomatePal makes it a conversation - products, plans, checkout, invoices, revenue analytics and dunning, all on the PayPal developer platform with a Gemini agent. Deployed on Render, dashboard on AG Grid. Everything you just saw is open source - link below."

## Recording checklist
- [ ] Seed data first so dashboard is alive
- [ ] Use sandbox links only (visible "sandbox" in URL is fine - required)
- [ ] No PayPal logo or wordmark anywhere on screen; refer to PayPal in text/voice only ("built with the PayPal developer platform")
- [ ] End card: "PayPal is a trademark of PayPal, Inc. AutomatePal is not affiliated with or endorsed by PayPal."
- [ ] No third-party logos/music; plain screen + voice
- [ ] Export 1080p, upload to YouTube as public, paste link into Devpost
